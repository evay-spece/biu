找鸭 1.2.8（构建53）

新增：
- 搜索主窗默认宽度760（原920），最小700；搜索框与主页两侧留白收紧，文件类型筛选适应窄窗。
- 金额换算为两行独立输入：第一行默认美元→人民币，第二行默认人民币→美元；金额、币种及结果彼此独立。汇率表保留人民币兑换美元参考行。
- 常用软件区提供单个“最近打开App”图标，点击展开最近5个App列表，已固定项去重，点击打开、加号固定；本机记录最近启动/切换的普通应用，首次以当前运行App的启动时间填充。

此前依据《找鸭修改》21:58版清单实现：
- 主页软件通知角标：读取Dock提供的实际通知数量，需辅助功能权限；无权限或无可读数量时不显示。不会推测或读取聊天内容。
- 标签栏只显示索引中有文件使用的标签，文字标签优先；选中用底色，不再添加勾号。
- 搜索匹配词采用圆角高亮底；右键颜色标签悬停放大，未添加显示+、已添加显示−。
- 编辑标签/备注后，当前结果保持位置；更改关键词、范围、类型或排序后再应用标记优先排序。
- 快捷文本增加悬停反馈，双击才复制，保留编辑、删除。
- 人民币参考汇率紧凑排版，支持手动金额、双向及币种之间换算。
- 世界时间采用城市卡片，时间换算只输入月、日、时、分；使用当前年份，校验无效日期及夏令时。
- 已选快捷范围或自定义目录再次点击可取消，保留关键词。
- 新增常用文件区，放在常用软件下方；原文件夹入口自动归入，文件和文件夹均可固定，显示标签和备注。
- 搜索结果右键可固定到首页；常用文件区支持从Finder等位置拖入。
- 主页入口使用原生拖放调整组内顺序，拖动不触发启动；其他图标以0.18秒平滑让位，成功放下后保存，取消回到原顺序，支持系统减少动态效果设置。
- F1–F12可以单独录制为全局快捷键；其他按键仍需修饰键，系统快捷键冲突会提示。键盘若优先输出亮度/音量，需使用标准功能键模式。
