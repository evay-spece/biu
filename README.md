# Biu

**把文件搜索、应用启动和常用操作放在一个地方。**

Biu 是一款 macOS 效率工具：用一个搜索框查找本地磁盘和 SMB 共享盘中的文件，也可以快速打开应用、网站和日常工具。

[下载最新版 Biu 1.5.7](https://github.com/evay-spece/biu/releases/latest) · [查看所有版本](https://github.com/evay-spece/biu/releases)

## 重点功能

### 本地与 SMB 文件搜索

- 搜索本地磁盘和已连接的 SMB 共享盘中的文件与文件夹。
- 本地文件使用 Oil Find 索引，支持文件变化后的增量更新。
- 按文件类型、修改时间、最近打开等条件筛选和排序。
- 查看文件修改时间，打开文件或直接定位到所在文件夹。
- 可将常用目录加入首页，也可在搜索结果中固定文件和文件夹。

### 应用、文件、网站与工具启动器

- 在首页集中放置常用应用、文件夹、网站和快捷功能。
- 拖动图标调整顺序；支持最近打开的 App。
- 使用全局快捷键呼出搜索，也可从菜单栏访问。

### 剪贴板历史与快捷文本

- 保存近期复制的文本、图片和文件，支持搜索、分组、收藏和再次复制。
- 把常用内容保存为快捷文本，需要时快速搜索和复制。

### 文件标签与备注

- 为文件添加颜色标签和文字标签，并可添加多个标签。
- 用备注记录用途、状态或其他提示；标签和备注保存在本机。

### 日常小工具

- 人民币与美元金额换算、世界时间查询。
- 快速搜索网页，或直接使用百度、小红书和淘宝搜索。

## 下载与安装

1. 打开 [最新版发布页](https://github.com/evay-spece/biu/releases/latest)。
2. 下载 `Biu-1.5.7-macOS-arm64.zip` 并解压。
3. 将 `Biu.app` 拖入“应用程序”文件夹后打开。

需要 **Apple Silicon（M 系列芯片）**，系统为 **macOS 14 或更新版本**。当前安装包使用 ad-hoc 签名，未经 Apple 公证；首次打开时 macOS 可能显示安全提示。

## 共享盘使用说明

先在 Finder 中连接 SMB 共享盘，再在 Biu 中添加共享目录并建立索引。共享盘的索引由 Biu 在本机维护；搜索时共享盘需要处于可连接状态。

## 许可证与第三方组件

Biu 使用 Oil Find 作为本地文件索引组件。相关许可和第三方声明随源码及应用包提供，详见仓库中的 `THIRD_PARTY_NOTICES.md`。
